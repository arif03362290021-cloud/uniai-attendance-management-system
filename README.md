## Project Overview
UniAI Attendance Management System is a modern web application designed to solve the problem of manual attendance tracking in universities and colleges. 
The goal of this project is to save teachers' valuable time and make the entire attendance process 100% digital, fast, and error-free.

## Problem Statement
Traditionally, teachers at universities like Kohat University record student attendance manually in paper registers. This process is slow, repetitive, and prone to human errors. It is also very difficult to generate reports or analyze student data over time.

## Proposed Solution
This application digitizes the entire attendance workflow. Teachers can securely log in, select a class, and mark attendance for all students with a single click. The system stores all data centrally and allows admins to generate and export reports instantly.

## Key Features
- **Secure Authentication:** Role-based login for Teachers and Admins
- **One-Click Attendance:** Mark attendance for an entire class in under 60 seconds
- **Student & Batch Management:** Easily add, edit, and manage student records
- **Analytics Dashboard:** View real-time attendance statistics and trends
- **Export Reports:** Download attendance data as a CSV file for records
- **Fully Responsive:** Optimized for Desktop, Tablet, and Mobile devices
- **Time Efficient:** Saves an average of 15 minutes per class

## How to Use
1.  **Login:** Access the system using your assigned Teacher/Admin credentials.
2.  **Select Class:** Choose the specific class or batch from the dashboard.
3.  **Mark Attendance:** Mark students as Present or Absent and click 'Save'.
4.  **View & Export:** Navigate to the 'Reports' section to view history and export data.
